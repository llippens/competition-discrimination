# About
Data and code related to the project 'Competition and hiring discrimination: A meta-reanalysis of correspondence experiments'.

Please refer to the [OSF-project](https://osf.io/mgc4y) for more details and a preregistration document.

# Cite
When using or referring to the materials presented here, please cite as:
```
Lippens, L., & Baert, S. (2025). A meta-reanalysis of correspondence experiments on hiring discrimination. Retrieved from https://osf.io/mgc4y
```
